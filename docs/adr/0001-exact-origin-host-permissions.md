# Grant host access per configured CLIProxyAPI origin

The extension supports one user-configured CLIProxyAPI Instance without receiving required access to every website. The configured base URL must contain only an HTTP(S) origin: a custom port is allowed, a trailing `/` is normalized, and path prefixes, query strings, fragments, and URL userinfo are rejected. It declares localhost and HTTPS patterns only as `optional_host_permissions`, then requests the exact configured origin synchronously from the Save user gesture before validation. A failed validation revokes the newly granted origin and preserves the previous connection; only a successfully validated and saved replacement causes the previous origin permission to be removed. Remote connections require HTTPS, while HTTP is permitted only for `localhost` and `127.0.0.1`.
